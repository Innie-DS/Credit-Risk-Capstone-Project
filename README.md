# CREDIT RISK AND LOAN DEFAULT PREDICTION
A data Science project exploring credit risk, borrower characteristics, and loan default prediction.

## Project Overview

This project explores credit risk and loan default prediction using borrower and loan information. The goal is to understand patterns associated with loan defaults and evaluate machine learning models that could help lenders assess risk.

## Tools Used

- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- SQL

## Project Structure

The main Notebook contains the data cleaning, exploratory data analysis, feature engineering, clustering, classification, model evaluation, and business recommendations.
